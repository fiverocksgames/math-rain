# 🌧️ Math Rain

떨어지는 수학 문제를 보고 정답 카드를 찾아 맞히는 간단한 연산 게임입니다.

**빠르게 계산하고, 빗방울이 바닥에 닿기 전에 정답을 찾아보세요!**

[🎮 Math Rain 플레이하기](https://fiverocksgames.github.io/math-rain/)

## 🎯 게임 방법

1. 레벨과 연산 종류, 난이도, 자릿수를 선택합니다.
2. 화면 위에서 수학 문제가 빗방울처럼 떨어집니다.
3. 아래의 숫자 카드에서 정답을 선택합니다.
4. 빗방울이 바닥에 닿기 전에 최대한 많은 문제를 해결하세요.

## ✨ 주요 기능

- ➕ 덧셈 / ➖ 뺄셈 / ✖️ 곱셈 / ➗ 나눗셈
- 🔀 여러 연산을 섞은 혼합 모드
- 🎚️ Easy / Normal / Hard 난이도
- 🔢 1자리부터 2자리 연산까지 선택
- 🌧️ 레벨이 올라갈수록 동시에 등장하는 문제가 증가
- ❤️ 3개의 생명
- 🔥 연속 정답 콤보와 추가 점수
- 📊 게임 종료 후 점수와 정확도 확인
- 📱 모바일 화면 지원

## 🚀 Run Locally

별도의 빌드 과정이나 패키지 설치가 필요하지 않습니다.

```bash
git clone https://github.com/fiverocksgames/math-rain.git
cd math-rain
```

저장소를 clone한 뒤 간단한 로컬 웹 서버로 실행하거나 GitHub Pages에서 바로 플레이할 수 있습니다.
